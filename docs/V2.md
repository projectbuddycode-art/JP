# Travel CRM v2 — partner OS

Additive upgrade. Existing CRM screens, demo auth, WhatsApp/social/automation cores, and visual identity are preserved.

## Migrations

Apply in order: `0001_init.sql`, `0002_rls.sql`, `0003_partner_intelligence.sql`, `0004_rls_v2.sql`. No drops of production tables.

## Roles

| Role | Typical access |
| --- | --- |
| owner | Users, settings, integrations, automations, all records, audit, revenue |
| admin | Operations, reports, assign leads; not users/integrations/settings |
| partner | Own leads, notes, tasks, own performance |
| sales | Assigned pipeline work |
| viewer | Read-only permitted reports/leads |

Permissions are checked in server actions (`assertPermission`) and RLS (`0004_rls_v2.sql`). Hiding nav is not the security boundary.

## Reports

Definitions live in `src/lib/reports/intelligence.ts`. Recorded revenue is confirmed booking value, not cash and not proposals.
