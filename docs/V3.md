# V3 feature inventory

Existing modules were mapped into four systems. Nothing listed as kept was deleted.

## System A — Public website

| Feature | Location |
|---|---|
| Homepage, destinations, trips, enquire, custom trip, about, guides, contact, policies | `src/app/(marketing)` |
| SEO, sitemap, robots | `src/app/sitemap.ts`, `robots.ts`, `src/lib/site/seo.ts` |
| Package publish | CRM `/packages`, `/website` |
| Newsletter / WhatsApp CTA | site components (consent required) |

## System B — CRM and sales

| Feature | Location |
|---|---|
| Lead inbox, pipeline, contacts, WhatsApp inbox, proposals, bookings | `/sales`, `/leads`, `/pipeline`, `/contacts`, `/inbox`, `/bookings` |
| Unified ingest | `src/lib/ingest/engine.ts` |
| Scoring | `src/lib/crm/score.ts` (transparent rules) |
| Duplicate review | `/leads/duplicates` |
| Repeat customers | `/sales/retention` |
| CSV import | Enquiries → New lead / CSV |

## System C — Trip operations

| Feature | Location |
|---|---|
| Departures, travellers, itinerary, suppliers, readiness, live trip | `/departures`, `/travellers`, `/operations`, `/departures/[id]/live` |
| Payments vs collected cash | `/bookings`, `src/lib/ops/finance.ts` |

## System D — Business management

| Feature | Location |
|---|---|
| Reports | `/reports`, `/reports/register` |
| Team, audit, automation, integrations, approvals, settings | matching routes |
| n8n | Primary scheduler (`docs/N8N.md`). Vercel Hobby has no job cron. |

## Roles

owner, admin, operations_manager, partner, sales, trip_leader, finance, viewer.

## Honest gaps

- Excel/PDF exports remain CSV plus browser print unless a licensed export library is added.
- Meta, WhatsApp, Google Ads, LinkedIn, TikTok stay Not Connected until credentials and a verified event succeed.
- No GPS tracking.
- Testimonials only if published from CRM records.
